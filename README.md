# LESCO Complaint Registration

Separate Android app for registering LESCO IT support complaints from a mobile phone.

## Backend
Uses the same Google Apps Script Web App endpoint and the same complaint fields as the existing LESCO Support Alert system:
- Sub Division Code
- Operator Name
- Mobile Number
- Date
- Issue Type
- Issue / Problem

On successful registration it displays the generated Ticket No, Security Key (when generated by the backend), and Status.

## GitHub Actions
1. Create a new GitHub repository.
2. Upload this project.
3. Push to `main` or open **Actions → Build LESCO Complaint Registration APK → Run workflow**.
4. Download the APK from the workflow artifact.

The app has a separate application ID (`com.lesco.supportregistration`) so it can be installed alongside the existing monitoring app.
